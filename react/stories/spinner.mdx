# Spinner

A loading indicator to show while retrieving data or performing slow computations. It renders the [Optics spinner](https://docs.optics.rolemodel.design/?path=/docs/components-spinner--docs) classes.

**Optics version:** 2.6.1

```sh
npx shadcn@latest add https://docs.optics.rolemodel.design/r/spinner.json
```

## Playground

<Canvas of={SpinnerStories.Default} />
<Controls of={SpinnerStories.Default} />

## Props

`Spinner` renders a `div.spinner` with `role="status"` and a visually hidden `label` (default `Loading`) for assistive technology. Set `label` to say what is loading. Any other `div` attribute is passed through.

## Variations

`Spinner` without a `size` is a large spinner.

## Customizing

The component only adds classes, so you style it the same way as the CSS version. See [Spinner API](https://docs.optics.rolemodel.design/?path=/docs/components-spinner--docs#spinner-api) for the CSS variables.
