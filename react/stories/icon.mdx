# Icon

An icon from the [Material Symbols](https://fonts.google.com/icons) font, or an inline SVG. It renders the [Optics icon](https://docs.optics.rolemodel.design/?path=/docs/components-icon--docs) classes.

```sh
npx shadcn@latest add https://docs.optics.rolemodel.design/r/icon.json
```

## Props

`Icon` renders a `span.icon` and takes `size`, `weight`, `emphasis`, and `label`, and any `span` attribute. Give it either:

- `name`: a Material Symbols icon name. It adds `material-symbols-outlined`, and takes `filled`.
- an `svg` as children. It adds `icon--svg`.

Without `label` the icon is decorative and gets `aria-hidden`. With `label` it gets `role="img"` and that label.

Optics ships a Material Symbols font with only the weight axis. `filled` and `emphasis` need the full variable font. See [Icon](https://docs.optics.rolemodel.design/?path=/docs/components-icon--docs) for the font imports and for other icon fonts, which use their own classes.

## Variations

### Default

`name` is the Material Symbols icon to show, such as `settings`.

<Canvas of={IconStories.Default} />

### Filled

`filled` shows the filled (`true`) or outlined (`false`) icon. Unset looks outlined.

<Canvas of={IconStories.Filled} />

### Size

`size` is `small`, `medium`, `large`, or `x-large`. Unset looks the same as `medium`.

<Canvas of={IconStories.Size} />

### Weight

`weight` is `light`, `normal`, `semi-bold`, or `bold` and sets the stroke weight. Unset looks the same as `normal`.

<Canvas of={IconStories.Weight} />

### Emphasis

Emphasis acts like weight, but changes the thickness of the strokes in subtle ways. `emphasis` is `low`, `normal`, or `high`. Unset looks the same as `normal`.

<Canvas of={IconStories.Emphasis} />

### SVG Icons

Pass an inline `svg` as children instead of `name` to draw an icon from an SVG set such as [Hugeicons](https://hugeicons.com), or to ship only the Lucide, Tabler, or Phosphor icons your app uses.

<Canvas of={IconStories.Svg} />

- **Color:** the SVG uses `currentColor`, so it follows the text color.
- **Size:** `size` works as it does for fonts. The SVG fills the icon box.
- **Weight:** the stroke keeps the width the set drew until `weight` is set. Then it sets the stroke width of every stroked element.
- **Emphasis:** `emphasis="low"` lowers the opacity. Normal and high look the same.
- **Fill:** SVG sets draw filled icons as a separate style, so `Icon` does not take `filled` with an SVG.

## Customizing

The component only adds classes, so you style it the same way as the CSS version. See [Icon API](https://docs.optics.rolemodel.design/?path=/docs/components-icon--docs#icon-api) for the CSS variables.
