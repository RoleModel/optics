# Grid

A dynamic grid layout, for simple layouts with a minimum column size or evenly divided columns from 2 to 6. It renders the [Optics grid](https://docs.optics.rolemodel.design/?path=/docs/utilities-advanced-grid--docs) utility class.

**Optics version:** 2.6.1

```sh
npx shadcn@latest add https://docs.optics.rolemodel.design/r/grid.json
```

## Props

| Prop      | Values                                      | Adds                |
| --------- | ------------------------------------------- | ------------------- |
| `columns` | `2`, `3`, `4`, `5`, `6`                     | `op-grid--*-column` |
| `gap`     | `none`, `xxs`, `xs`, `sm`, `md`, `lg`, `xl` | `gap-*`             |

`Grid` renders `div.op-grid` and passes any other `div` attribute through. The examples on this page are in a `10rem` tall container.

## Customizing

The component only adds classes, so you style it the same way as the CSS version. See [Grid](https://docs.optics.rolemodel.design/?path=/docs/utilities-advanced-grid--docs) for the utility classes.
