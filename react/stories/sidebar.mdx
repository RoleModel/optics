# Sidebar

A navigation sidebar in a drawer, compact, or rail size. It renders the [Optics sidebar](https://docs.optics.rolemodel.design/?path=/docs/components-sidebar--docs) classes.

To fit a sidebar into your application layout, see [Layout With Sidebar](https://docs.optics.rolemodel.design/?path=/docs/recipes-layout--sidebar). These examples put it in a `div.app-with-sidebar` with a fixed height so it fits on this page.

**Optics version:** 2.6.1

```sh
npx shadcn@latest add https://docs.optics.rolemodel.design/r/sidebar.json
```

## Parts

| Part              | Renders            | Props                                                               |
| ----------------- | ------------------ | ------------------------------------------------------------------- |
| `Sidebar.Root`    | `nav.sidebar`      | `size`: `drawer`, `compact`, `rail`. `variant`: `primary`. `padded` |
| `Sidebar.Brand`   | `a.sidebar__brand` | Any `a` attribute. Put an `img` inside                              |
| `Sidebar.Content` | `sidebar__content` | `justify`: `start`, `center`, `end`. Default is `start`             |

Put a borderless [Button](?path=/docs/components-button--docs) with an `Icon` and a label in `Sidebar.Content` for each link. The size of the sidebar changes how the buttons look:

- Drawer shows the normal button style, aligned left
- Compact stacks the icon above the label
- Rail shows only the icon and hides the label

To make the sidebar responsive, change `size` as the window resizes, for example `drawer` above 1024px, `compact` above 768px, and `rail` below that.

`Sidebar.Brand` holds an image, such as your application's logo.

The brand is optional, and the sidebar content adjusts without it.

## Customizing

The component only adds classes, so you style it the same way as the CSS version. See [Sidebar API](https://docs.optics.rolemodel.design/?path=/docs/components-sidebar--docs#sidebar-api) for the CSS variables.
