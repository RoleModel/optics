# Button Group

A container that joins a collection of [Buttons](?path=/docs/components-button--docs). It works with every button variation. It renders the [Optics button group](https://docs.optics.rolemodel.design/?path=/docs/components-buttongroup--docs) classes.

Button Group is for grouping related actions or navigational buttons. Use [Segmented Control](?path=/docs/components-segmented-control--docs) for form option selection instead.

**Optics version:** 2.6.1

```sh
npx shadcn@latest add https://docs.optics.rolemodel.design/r/button-group.json
```

## Props

`ButtonGroup` renders a `div.btn-group` with `role="group"` and takes any `div` attribute. Style the buttons inside it with the `Button` props.

## Customizing

The component only adds classes, so you style it the same way as the CSS version. See [Button Group API](https://docs.optics.rolemodel.design/?path=/docs/components-buttongroup--docs#button-group-api) for the CSS variables.
